## 真实限制

- 本机 GUI 使用 macOS 27；macOS 26 是 CI 构建与测试证据，不代表 macOS 26 本机 GUI 或完整设备矩阵。
- AX 部分文本已取得时，整体质量仍可能保守显示不可用；不同目标应用支持不同。
- 系统录屏权限变化在当前进程内可能仍返回旧预检结果；本次撤权后实际截图已停止，界面显示采样失败，重新打开 App 后权限状态更新。恢复录屏时遵循系统重启要求。
- 正式 Sparkle 自动重启未继承测试注入的临时 HOME；恢复同一隔离目录后，对 records、evidence、activity_annotations、reports、report_candidates 五张表逐行比较一致。数据保留验证与环境继承是两个不同结论。
- 睡眠空档仅对当次未分析的 pending 观测时间线验证，没有推广为所有已分析组合。
- 异常更新使用独立进程、本地网络响应注入与公开测试签名向量；没有修改正式 App、TLS 或签名校验，也没有向公开 Release 投放坏资产。这不是正式 App GUI 对每种坏资产的逐项测试。
- 未验证用户现有 Codex/Claude CLI 登录身份、Claude 安装实例、独立视觉准确率或全部模型别名与设备组合。

上述验收使用受控合成样本，过程记录和产物保持在本地忽略目录，公开仓库不包含个人记录、测试数据库或凭据。0.1.0 的 tag 和发布资产保持原样；后续运行代码修复应使用新版本发布。
