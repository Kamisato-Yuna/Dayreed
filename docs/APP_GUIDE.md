# 使用 Dayreed

Dayreed 的主窗口提供时间线、日报和周报，设置位于独立窗口（⌘,）。数据只保存在本机，不需要账号。

## 采集与隐私

首次启动全部来源关闭。进入设置的“采集与隐私”，独立选择截图或应用历史；窗口标题和辅助功能文本分别选择，并随历史总开关生效。设置采样间隔、排除应用的 Bundle ID 和保留天数后应用。已保存的来源选择在日常启动时恢复。

屏幕录制与辅助功能权限由各自按钮显式申请。打开 App、读取记录或打开设置不会自动弹出权限申请。授权后使用“刷新权限状态”检查；系统可能要求重新打开 App。

“开始 / 暂停 / 继续 / 停止”控制实际采集。系统锁定、睡眠或会话非活跃时暂停采样。界面的运行状态代表调度，最近各来源质量说明实际取得的内容。所有来源关闭后仍能查看旧记录。

删除前先选择具体日期并查看范围；采集会暂停。确认后删除记录、证据及受影响报告和候选，界面刷新，采集保持暂停。删除不会清理系统快照或外部备份。

## 回顾与报告

⌘1 / ⌘2 / ⌘3 切换时间线、日报和周报；⌘[ / ⌘] 切换日期，⇧⌘T 回到今天。周报按本机时区从周一开始。

时间线使用真实观测点及相邻观测支持的时段；缺样不推算为持续活动。分析后的活动可以纠正标题和摘要，合并事件的观测一起保存。人工纠正会保留，受影响报告提示复核。

报告可以直接编辑 Markdown 并按 ⌘S 保存，即使当日没有采集记录也可写手工日报。未保存草稿在切换日期时会提醒。重新生成报告先从已有摘要产生候选，原报告保留；审查候选并明确选择替换后才更新报告。并发修改或来源变化会拒绝过期候选。

证据列表只显示来源标签。点击后才在本机窗口读取原始截图或文本；不导出临时副本，关闭窗口释放显示内容。

## 只读 Agent

设置的 Agent 页面显示包内 CLI 和默认终端链接状态，可复制 MCP 配置或安装命令。MCP 使用当前 App 的完整 Helper 路径，移动 App 后需要重新复制配置。

Agent 1.0 仅提供时间线、日报/周报、状态查询，无修改或原始证据工具。显式运行 CLI 不需要额外启用开关，也不会启动采集或分析。

## 更新

设置的更新页面使用实际更新控制器，提供手动检查和自动检查选择。无适用更新、下载、安装、取消和失败分别显示。正式更新需要完整、正确配置的 App；测试环境或未配置签名密钥时会明确显示不可用。
