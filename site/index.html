01 / 为自己留下记录

工作有痕，
回顾有据。

截图与应用历史，由你独立选择。
时间线串起工作片段，
日报和周报留住思考。

像芦苇一样，
在自己的节奏里生长。

1选择记录来源默认关闭，按需开启。

截图和应用历史独立选择，窗口标题与辅助功能文本也由你控制。随时暂停，为不想记录的应用留白。

2回顾与修订报告可以编辑，重新生成先审阅。

回到时间线，纠正活动标题与摘要；将想法写进日报、周报。重新生成先产生候选，由你决定是否替换。

3连接自己的 Agent通过只读 CLI / MCP 查询摘要。

让你正在使用的 Agent 读取时间线与报告。接口只读，不提供修改或原始证据工具；App 内不另设 Chat。
